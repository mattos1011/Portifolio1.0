# Portfólio — Vicente

Site de portfólio simples com HTML, CSS e JS.

Como usar:

1. Abra `index.html` em um navegador.
2. Para personalizar, edite `index.html` e `style.css`.
3. Modifique o e‑mail do formulário em `index.html` para receber mensagens.

Arquivos:

- `index.html` — estrutura do site
- `style.css` — estilos
- `script.js` — interatividade mínima
